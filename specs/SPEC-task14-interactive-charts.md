# Spec: Task 14 - Interactive Equity Curve & Drawdown Visualizer

## Assumptions & Design Decisions

1. **Design System & Aesthetics**:
   - 100% institutional trading aesthetic (Zerodha Kite / Bloomberg / Koyfin style): hairline borders (`border-slate-200 dark:border-slate-800`), deep dark background `#0d131f` / `#0c1017`, Inter sans typography with `tabular-nums` for all time-series points.
   - Strictly zero generic AI pastel yellow/amber alert pills or neon thick borders.
   - Equity curve: emerald gradient (`#10b981`) for profitable trajectory, hairline high-water mark line, and crimson/rose (`#f43f5e`) for underwater drawdown area.
2. **Data Model & Backend Integration**:
   - Consumes `PerformanceReport.equity_curve` (trade-by-trade `EquityPoint`) and `PerformanceReport.daily_equity_curve` (`DailyEquityPoint`) generated by Task 11 (`CoreMetricsEngine`).
   - Gracefully handles empty tradebook state (0 trades) with an informative empty state illustration and import callout.
3. **Timeframe Filters**:
   - Standard financial time horizons:
     - `1W` (Last 7 days)
     - `1M` (Last 30 days)
     - `3M` (Last 90 days)
     - `1Y` (Last 365 days)
     - `ALL` (All time inception to date)
   - Dynamic downsampling: If dataset $> 500$ points in selected range, downsamples to preserve 60fps rendering without UI lag.
4. **Rendering Architecture**:
   - **Custom Responsive SVG Engine**: Zero external npm dependencies, 0 KB bundle increase, zero hydration mismatches, crisp rendering on high-DPI displays via `viewBox`, native CSS gradients, and seamless crosshair mouse tracker.
   - **Layout Versatility**: Tabbed toggle by default ("Cumulative Net P&L" vs "Underwater Drawdown") with an optional split-view mode.

---

## Objective

Build interactive, high-performance time-series visualizers for cumulative Net P&L (Equity Curve) and peak-to-trough decline (Underwater Drawdown Chart):
1. **Interactive Equity Curve (`equity-chart.tsx`)**:
   - Plots cumulative Net P&L over time with smooth area/line rendering.
   - High-Water Mark reference line showing all-time peak equity.
   - Interactive crosshair with pinned tooltip displaying: Date, Trade Symbol/Count, Net P&L of trade/day, Cumulative Net P&L, and Drawdown.
2. **Underwater Drawdown Chart (`drawdown-chart.tsx`)**:
   - Displays peak-to-trough declines as an inverted area chart below the 0 baseline.
   - Displays percentage drop (`-X.X%`) and rupee value (`-₹X,XXX.XX`).
3. **Unified Chart Container (`chart-container.tsx`)**:
   - Segmented toggle between **Cumulative Net P&L** and **Drawdown**.
   - Timeframe range selector pills (`1W`, `1M`, `3M`, `1Y`, `ALL`).
   - Integrated metrics callout (Current equity, Peak equity, Max drawdown in selected range).
4. **Zero-CLS Loading & Empty States (`chart-skeleton.tsx`)**:
   - Layout-matched skeleton loader with pulsating baseline grid.
   - Clean empty state onboarding view when no trades exist.

## Code Style & Conventions

- Strict TypeScript prop interfaces for chart points and container controls.
- Smooth Bézier curve generator (`d="M x y C x1 y1, x2 y2, x y"`) with area fill gradients (`linearGradient`).
- Hover crosshairs with zero lag using React pointer/mouse events.
- All financial metrics formatted using `formatCurrencyINR`, `formatSignedCurrency`, and `formatPercentage`.

## Testing Strategy

- **Test Framework**: `vitest` in `apps/web/tests/charts.test.ts` and `apps/web/tests/chart-components.test.tsx`.
- **Test Scenarios**:
  1. **Timeframe Filtering Math**:
     - `1W`: Filters points within the last 7 calendar days.
     - `1M`: Filters points within the last 30 calendar days.
     - `3M`: Filters points within the last 90 calendar days.
     - `1Y`: Filters points within the last 365 calendar days.
     - `ALL`: Preserves all points in chronologically sorted order.
     - Empty data slice handling when no trades fall within selected range.
  2. **Coordinate Normalization & Scale**:
     - Correct calculation of min, max, and zero-baseline Y coordinates.
     - Handles all-profit datasets (min $\ge 0$).
     - Handles all-loss datasets (max $\le 0$).
     - Handles flat breakeven datasets without `NaN` or divide-by-zero errors.
  3. **High-Water Mark Calculation**:
     - High-water mark stays horizontal or ascends, never declines.
     - Drawdown is exact arithmetic difference between cumulative P&L and high-water mark.
  4. **Component Rendering & Edge Cases**:
     - Renders empty state prompt when `data.length === 0`.
     - Renders skeleton when `isLoading === true`.
     - Crosshair tooltip emits accurate formatted rupee values with `+`/`-` signs.

## Boundaries

- **Always do**:
  - Use `tabular-nums` on all tooltip values and axis labels.
  - Format all currency using `formatSignedCurrency` or `formatCurrencyINR` (standard Indian `en-IN` grouping).
  - Provide fallback bounds when min === max to avoid division by zero.
  - Verify `npm test` and `npm run build` succeed before committing.
- **Ask first**:
  - Installing large third-party canvas bundles (> 500KB) if responsive SVG meets all requirements.
  - Changing the visual layout from a unified card container to a separate page.
- **Never do**:
  - Never use generic AI yellow/amber rounded boxes or warning triangles.
  - Never hardcode Western notation (`$100k` or `₹1.5M`).
  - Never allow chart rendering to freeze or crash on large trade datasets (use downsampling).
